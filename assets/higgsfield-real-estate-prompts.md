# Higgsfield Real Estate Video Prompt Templates

**Model:** `kling-v2-1-master` via Higgsfield's public API (`POST https://platform.higgsfield.ai/v1/image2video/kling`, body `params.model = "kling-v2-1-master"`) — Kling 3.0 Turbo was the original target but has no public API access as of 2026-08-11 (see revision history). `kling-v2-1-master` was chosen after live A/B testing against plain `kling-v2-1` and Seedance; confirmed via `params.model` enum validation these are the only two Kling variants Higgsfield's API currently exposes.
**Duration:** 5 seconds (Higgsfield API default for this model; not independently confirmed configurable)
**Resolution:** whatever `kling-v2-1-master` renders at by default — not an explicit request parameter on this endpoint (unlike Seedance, which does expose `resolution`)

Core formula: start zoomed in (or centered), move only within the boundaries of the original photo, explicitly block hallucinated objects, and lock straight vertical lines. This avoids the two most common failure modes — invented geometry (e.g. phantom doors) and flat "sliding picture" motion instead of real parallax.

**Revision history:**
- v2 (2026-08-11) — after reviewing actual generated clips (Higgsfield API, `kling-v2-1`/`kling-v2-1-master`), found two real failure modes the v1 prompts didn't prevent: (1) Zoom In/Out rendered as a flat digital crop-and-scale with zero parallax — confirmed by comparing start/mid/end frames, every object stayed in identical relative position, just enlarged uniformly, instead of a true 3D dolly where near objects shift/scale faster than far ones; (2) Pan Right/Left revealed entire invented areas (new doors, cabinets, furniture) beyond the source photo's edge, because a single flat photo has no ground truth past its own frame — asking the pan to "reveal more of the room" past that point forces the model to hallucinate. v2 fixes: explicit "not a flat zoom/crop, true 3D parallax required" language on the zoom moves, and a dialed-back pan distance + explicit no-invented-content escape hatch on the pan moves. Also added a shared negative prompt — Higgsfield's API has a real `negative_prompt` field, unused in v1.
- v3 (2026-08-11) — re-tested v2 on `kling-v2-1-master` by pulling actual frames from the results. v2's zoom fix technically produced real parallax, but the emphatic "true 3D dolly... vanishing point should shift" language pushed the model into visible corruption by the end of the clip (warped/duplicated architecture, glassy reflection artifacts, a hallucinated hallway bleeding through). v2's pan fix reduced but didn't eliminate hallucinated new decor/wall art past the frame edge. v3 softens the zoom language to a gentler, non-demanding parallax cue (removes the "vanishing point" instruction specifically, since that seems to be what triggered the worst artifacts) and shrinks the pan reveal to near-zero — treating the pan as a lateral drift within already-visible content rather than a "reveal" of new space at all. Negative prompt expanded to explicitly exclude reflections/mirrors/ghosting/duplicated architecture, which weren't called out in v2 and showed up as real artifacts. Result: v3 zoom is clean (no artifacts, subtle real parallax, faithful room preservation) — accepted. v3 pan is meaningfully better (no corruption) but still shows minor invented detail at the reveal edge (e.g. a small framed picture not in the source) — accepted as a reasonable trade-off given a single flat photo has no ground truth past its own edge; not expected to be fully eliminable via prompt wording alone on this model.
- v4 (2026-08-14) — root cause found for a recurring complaint that Higgsfield "ignores" the line "camera starts zoomed in at approximately 35%": Kling's image-to-video conditioning anchors frame 0 to the literal input photo, unmodified — confirmed directly by extracting frame 0 from multiple real generated clips (a staging test and a dedicated Zoom In v4 test) and finding it pixel-matched the source image every time, never pre-zoomed. The v1–v3 prompts' "starts zoomed in" framing was describing a starting state the model cannot produce. For Zoom In and Pan Left/Right this was harmless-but-ineffective — the actual movement (tightening crop, lateral drift) never needs pixels beyond the original photo regardless of the claimed start state. For Zoom Out it was doing real work: claiming the model "pulls back until the final frame matches the full original photo exactly" is only geometrically coherent if it truly started pre-zoomed; since it doesn't, that instruction was quietly asking the model to reveal space beyond the real (already-full) starting frame, which has no ground truth — the same hallucination risk v2/v3 already fought for pans, just undocumented for zoom out until now. v4 rewrites all four prompts to ground the start state in reality ("camera starts exactly at the framing of the original photo, unchanged"). Zoom In and the pans keep their movement logic, just described from the true start. Zoom Out is substantively redesigned: no longer a dramatic reveal-to-full-photo, but an extremely subtle "ease-back" explicitly barred from ever exceeding the original photo's boundaries — the same minimize-the-reveal fix already proven for pans in v3, applied to zoom out instead. Negative prompt gained explicit terms against pulling back beyond the photo's edges / revealing space beyond the original frame. **Verification status: Zoom In v4 was verified against real generated frames (frame 0 matched source exactly; end frame showed a clean push-in with real parallax, no hallucination, straight lines held) — accepted. Pan Right, Pan Left, and Zoom Out v4 were shipped WITHOUT live frame verification** — the Higgsfield API credit pool (separate from the consumer app subscription, see CLAUDE.md §5) ran out mid-test before those three could be submitted, and the call was made to ship the reasoning-based fix rather than wait. If pan or zoom-out clips look off after this change, re-verify those three specifically against real frames before assuming the prompt wording is still at fault. **v4 is the current adopted prompt set — this is what n8n's `Build Clip Jobs` node should embed verbatim, alongside the negative prompt above and `model: "kling-v2-1-master"`.**

## Negative prompt (use for all four movements)

Pass this in Higgsfield's `negative_prompt` field alongside every request, regardless of movement:

extra people, human figures, pets, animals, invented furniture, new doorways, new rooms, new wall art, new decor, extra windows, warped architecture, duplicated columns, distorted geometry, morphing walls, glass reflections, mirror artifacts, ghosting, flat sliding image, static crop zoom, digital zoom artifact, camera pulling back beyond the original photo's edges, wider framing than the original photo, revealing space beyond the original frame, watermark, text overlay, blurry, low quality artifacts

---

## 1. Zoom In / Push-In

Camera starts exactly at the framing of the original photo, unchanged, then performs a slow, smooth cinematic push-in toward the center of the room, continuing to advance gently. The motion should have a natural sense of depth — foreground elements move and grow slightly more than elements further back, giving the push-in a subtle three-dimensional feel rather than a flat, static image zoom. Keep this effect subtle and natural, not exaggerated. Camera stays locked on-axis, moving forward only, no lateral movement. Preserve exact room contents, furniture, layout, lighting, and architecture from the source image — do not add, invent, or hallucinate any objects, doors, windows, reflections, or elements not visible in the original photo. Vertical lines on walls, windows, and door frames stay perfectly straight throughout. Realistic depth of field, sharp focus maintained on foreground and midground. Natural shadow behavior as the camera moves closer. Professional real estate videography quality, steady and clean, 5–6 seconds.

---

## 2. Pan Right

Camera starts exactly at the framing of the original photo, unchanged, then performs a very slow, subtle pan to the right combined with a gentle zoom in — gradually tightening the frame while drifting the visible window to the right, staying entirely within content already visible in the original photo. The framing must never extend past the right edge of the original photo; if approaching that edge, ease off the movement rather than reveal any new space. Do not reveal an entire new area of the room, a new doorway, new furniture, or a new room beyond what is already visible in the source image. Preserve exact room contents, furniture, layout, lighting, and architecture — do not add, invent, or hallucinate any objects, doors, windows, people, reflections, or elements not visible in the original photo. Vertical lines on walls, windows, and door frames stay perfectly straight throughout. Natural parallax, foreground elements shift slightly faster than the background. Realistic depth of field and shadow behavior. Professional real estate videography quality, steady and clean, 5–6 seconds.

## 3. Pan Left

Camera starts exactly at the framing of the original photo, unchanged, then performs a very slow, subtle pan to the left combined with a gentle zoom in — gradually tightening the frame while drifting the visible window to the left, staying entirely within content already visible in the original photo. The framing must never extend past the left edge of the original photo; if approaching that edge, ease off the movement rather than reveal any new space. Do not reveal an entire new area of the room, a new doorway, new furniture, or a new room beyond what is already visible in the source image. ## 4. Zoom Out / Pull-Back

Camera starts exactly at the framing of the original photo, unchanged, then performs an extremely slow, subtle ease-back — a gentle release of tension rather than a dramatic reveal, as if settling back a small fraction from the exact starting frame. The framing must never extend beyond the boundaries of the original photo at any point — no new walls, space, or rooms may become visible beyond what the source image already shows. If a wider framing would require revealing anything not already present in the original photo, do not perform it; keep the movement minimal enough to stay entirely within the original photo's visible content throughout. The motion should feel calm and barely perceptible, cinematic, not a dramatic zoom-out. Preserve exact room contents, furniture, layout, lighting, and architecture from the source image — do not add, invent, or hallucinate any objects, doors, windows, reflections, or elements not visible in the original photo. Vertical lines on walls, windows, and door frames stay perfectly straight throughout. Realistic depth of field and shadow behavior. Professional real estate videography quality, steady and clean, 5–6 seconds.
